
# 🌿 Matcha Maps

Aesthetic café discovery across India.

Matcha Maps helps users discover cafés based on location, budget, ratings, and vibe.

## Tech Stack

- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: PostgreSQL
- Maps: Leaflet + OpenStreetMap
